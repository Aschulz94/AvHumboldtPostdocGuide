# Templates

Downloadable starting files for every document you write yourself. On GitHub, open a file and click **Download raw file** (⬇), or download the whole repo via **Code → Download ZIP**.

| File | What it is | How to use it |
|---|---|---|
| [`2pageCV_Example.pdf`](2pageCV_Example.pdf) | Two-page CV, no publications | Layout and section-order reference |
| [`research-statement-latex/`](research-statement-latex/) | LaTeX source for the 5-page research outline (`main.tex`, `refsbib.bib`, `fig1.png`) | Edit locally, or use the `.zip` below for Overleaf |
| [`HumboldtApp_OverleafTemplate.zip`](HumboldtApp_OverleafTemplate.zip) | Same LaTeX template, zipped | Overleaf → **New Project → Upload Project** → select the zip |
| [`Humboldt_ListOfPubs_Example.docx`](Humboldt_ListOfPubs_Example.docx) | Complete publication list in the Foundation's model format | Replace entries with your own; keep the section headings |
| [`ListOfKeyPublications_Example.docx`](ListOfKeyPublications_Example.docx) | Key publications with justification paragraphs | Keep the citation + paragraph structure |
| [`HumboldtOnlineResearchForm_Guide.pdf`](HumboldtOnlineResearchForm_Guide.pdf) | The full online questionnaire, field by field (Nov 2023) | Draft your answers offline before opening the portal |

Formatting details for each template: [`../FORMAT_EXAMPLES.md`](../FORMAT_EXAMPLES.md)

*Templates last updated November 2023. Check the [official Humboldt page](https://www.humboldt-foundation.de/en/apply/sponsorship-programmes/humboldt-research-fellowship) for current requirements.*
