# Contributing to AvHumboldtPostdocGuide

Thank you for considering sharing your materials! Seeing real, finished applications is the single most useful thing for someone writing their first Humboldt proposal.

## What we're looking for

Materials from **successful** Humboldt Research Fellowship applications (either track, any field, any year):

- Two-page CVs
- Research outlines / research statements
- Complete publication lists
- Key publication lists (with justification paragraphs)
- Online-form text: title, summary, keywords, impact statement
- Anything else that helped — a project timeline, the email you sent a prospective host, notes from the post-award process

Partial sets are welcome. A single document is still useful.

We also welcome **corrections and updates to the guide** — especially if the Foundation's rules, forms, or character limits have changed since the last update.

## Before you send: redact

Your materials will be public. Please remove or black out:

- Phone numbers, home addresses, and personal email addresses
- Unpublished results or ideas you aren't ready to share
- Anything identifying your reviewers or confidential host information

Redacted text is fine — the structure and writing are what people learn from.

## File format and naming

- Send **PDFs** (Word/LaTeX source is welcome *in addition*, if you're happy to share an editable version).
- Name files: `<LastName>_<DocType>_<Year>_<Field>.pdf`

| DocType | Use for |
|---|---|
| `CV` | Two-page CV |
| `ResearchStatement` | 5-page research outline |
| `PubList` | Complete publication list |
| `KeyPubs` | Key publications list |
| `Abstract` | Online-form summary / keywords / impact text |
| `Other` | Anything else (add a short description in the PR or email) |

Example: `Schulz_ResearchStatement_2023_Biomechanics.pdf`

If you'd prefer to stay anonymous, use `Anon` in place of your last name.

## How to submit

**Option 1 — Email (easiest):** send files to [aschulz@is.mpg.de](mailto:aschulz@is.mpg.de) with:
- Your name (or "anonymous"), track (postdoc / experienced), field, year of award, and German host institution (optional)
- Which license you'd like (default below)

**Option 2 — Pull request:**
1. Fork the repo.
2. Add your files to the matching folder in [`examples/`](examples/).
3. Add a row to the table in [`examples/README.md`](examples/README.md).
4. Open a pull request with a one-line description.
