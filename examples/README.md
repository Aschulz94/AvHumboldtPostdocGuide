# Example Library: Successful Humboldt Applications

Every file in this folder was part of a **funded** Humboldt Research Fellowship application, shared by the fellow so others can see what a finished document looks like.

> These are examples, not formulas. Fields differ in what reviewers expect — read a few, then write in your own voice. Please don't copy text; reuse with credit per each file's license.
